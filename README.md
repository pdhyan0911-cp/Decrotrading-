# DecroTrade — Learn the Market. Master the Strategy.

DecroTrade is an institutional-grade trading education, interactive market analysis, virtual practice simulator, and gamified learning platform.

---

## 🌟 Key Features

- **10 Comprehensive Courses:**
  1. Market Fundamentals
  2. Candlestick Patterns
  3. Charts and Price Action
  4. Technical Analysis
  5. Support and Resistance
  6. Indicators and Trend Analysis
  7. Risk Management (1% Rule & Drawdown Math)
  8. Trading Psychology (Loss Aversion & Overcoming Tilt)
  9. Strategy Development & Expectancy
  10. Advanced Market Concepts (Liquidity Sweeps & FVGs)
- **Interactive SVG Charting Engine:** Candlestick, Line, and Bar modes with crosshair tracking, OHLC metrics, SMA 20, EMA 50, Bollinger Bands, RSI 14, Volume histograms, and Support/Resistance zones.
- **Virtual Practice Simulator:** $100,000 virtual balance for paper trading equities, crypto, forex, and commodities with automated Stop-Loss and Take-Profit triggers.
- **Nova AI Learning Assistant:** Powered by Google Gemini (`gemini-3.8-flash`) with educational fallback for pattern explanations, journal reviews, and quiz generation.
- **7 Educational Challenges:** Timed quizzes with scoring, XP rewards, achievement badges, and global leaderboards.
- **Trade Journal:** Psychological state tracking, plan adherence tags, and AI-assisted reviews.
- **Admin Control Center:** User account moderation, role toggles, suspension toggles, and system telemetry.

## 🚀 One-Click Deploy on Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

1. Push this repository to your GitHub account.
2. In [Vercel](https://vercel.com), click **Add New Project** and select this repository.
3. Add the environment variable:
   - `GEMINI_API_KEY`: Your Gemini API key for Nova AI.
4. Click **Deploy**.

---

## 💻 Local Development

```bash
# 1. Install dependencies
npm install

# 2. Start the development server (runs full-stack Express + Vite on port 3000)
npm run dev

# 3. Build for production
npm run build
```

## 🛡️ Educational Safety Disclaimer

DecroTrade is an educational and simulated platform only. It does not accept cash deposits, process real-money payments, execute live brokerage transactions, or provide investment advice. All balances, achievements, and statistics represent virtual educational progress.
